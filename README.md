# 🎮 JUEGO | REN'PY | ING. EN VIDEOJUEGOS

¡Bienvenidos al proyecto de **novela visual desarrollado en Ren'Py**!

Este proyecto fue desarrollado con fines educativos para estudiantes de **Ingeniería en Videojuegos**, como parte de la materia **Motores Gráficos Aplicados a Videojuegos**.

A través de este ejercicio podrás explorar cómo se construye una novela visual utilizando Ren'Py, trabajando con código, diálogos, elementos narrativos y recursos gráficos para desarrollar una experiencia interactiva.

## 🎯 Objetivo del proyecto

Desarrollar una novela visual que permita poner en práctica los fundamentos de la narrativa interactiva y la programación de videojuegos, mediante el uso de diálogos, escenas, personajes y recursos gráficos.

## 🛠️ Tecnologías utilizadas

- **Motor de desarrollo:** Ren'Py
- **Versión de Ren'Py:** 8.5.3
- **Lenguaje de programación:** Python y lenguaje de scripting de Ren'Py
- **Tipo de proyecto:** Novela visual
- **Recursos gráficos:** Imágenes y assets utilizados en el proyecto

## 📂 Archivos del proyecto

### Código fuente y recursos gráficos
